# codex-image-director：方法原理

> 本文给人看，解释这套方法为什么有效。agent 执行任务时走 `SKILL.md` → `flows/`，不需要读本文。

## 一、精度从哪里来

生图模型每次只看到一段文字和几张图，不会追问，也不会自查。所以精度不靠某个神奇的关键词，靠的是在模型外面搭一个闭环：

```text
            ┌──────────────── 单变量返修 ◀───────────────┐
            ▼                                              │
 需求 ─▶ 画面设计 ─▶ 规格化提示词 ─▶ 执行（原样转述）─▶ 自己验收
         （导演）       （编剧）         （画师）          （质检）
```

| 角色 | 谁来做 | 做什么 |
|---|---|---|
| 导演 | agent | 补全用户没说的维度；推演物理和几何；预判冲突；把难画的形态改成好画的 |
| 编剧 | agent | 把审美要求翻译成可验证的英文约束；给每张参考图分工 |
| 画师 | image_gen | 照规格画 |
| 转述者 | Codex | 用包装语要求它原样转述、只调用一次，减少改写 |
| 质检 | agent | 自己看图，放大核对，照实报告差距，决定下一步怎么修 |

## 二、七条核心原理

1. **把审美翻译成可验证的约束**
   - “自然”“好看”“协调”没法验收。
   - “两段线交于一点”“各段等长”“约两指宽”“exactly three”“不接触”可以验收。
   - 能验收的约束，模型也更容易照做。
2. **补全用户没说的维度，但不添加用户没暗示的东西**
   - 用户通常只说主体和气质，镜头、透视、受力、手、光和环境层次都要补上。
   - 补全的边界：让画面成立的信息要补；新的人物、道具和剧情不加。
3. **预判失败模式，先改形态**
   - 细长物会画弯，比喻会被当成字面意思，不合常理的动作会被补出辅助结构，写实程度会滑到相邻档。
   - 预判到就先换形态或换写法，不等失败后再堆强调词。
4. **参考图分工**
   - 每张图都写清借什么、不借什么。
   - 只需要局部的先裁剪；平面设定图只借设计，不借画风。
5. **编辑和重生成各有边界**
   - 编辑能保住脸和构图，但挪不动构图，也很难大跨度改画风。
   - 重生成能大改，但细节可能漂移。
   - 选错手段比提示词写得差更浪费轮次。
6. **锁定清单逐项列出，每轮只改一处**
   - 只写“其他不变”约束力很弱，逐项点名才能锁住。
   - 一轮改多处，出了问题分不清是哪一处引起的。
7. **自己验收，照实报告**
   - 生成方对结果的自述不可靠。
   - 小细节要放大核对。
   - 没做到的照实说，并给出带代价说明的选项。
   - 用户反馈有歧义时，先复述再动手。

## 三、常见做法为什么效果差

| 常见做法 | 结果 | 本方法的做法 |
|---|---|---|
| 把用户原话直接发给模型 | 镜头、受力、手这些没说的维度全靠模型自己猜 | 补全维度，推演物理 |
| 堆质量标签（masterpiece、8k） | 没有证据表明有效，还挤掉了真正的约束 | 用写实刻度锚定词，加排除相邻档 |
| 用比喻和情绪词 | 被字面化，或者被放大 | 写形状；写程度并加排除 |
| 一个词定写实程度 | 落到插画感，或者写实过头 | 定档、写锚定词、排除相邻档 |
| 只写正面描述 | 模型自己补结构、自己选颜色 | 写“没有什么”和颜色排除 |
| 编辑时整段重写提示词 | 构图和脸一起漂移 | 用编辑模板，逐项锁定 |
| 把上一版当参考继续改 | 上一版的错误被继承下去 | 大改时只留必要的参考图 |
| 一次改好几处 | 新问题出现时无法定位原因 | 单变量返修 |
| 相信生成方说“已完成” | 交出去的图没达标 | 自己看图逐条对照 |
| 不确认就照自己的理解改 | 改错了方向，浪费一轮 | 先复述，确认后再改 |

## 四、决策权：什么时候问，什么时候自己定

生图过程中有很多取舍：比例、写实档位、冲突怎么解、编辑还是重生成、要不要继续修。

- 默认询问：用选择题问用户，推荐项排第一，同一阶段的问题一次问完。
- 用户授权“你看着办”时，按各流程《决策点》表里的默认值执行，交付时列出《我替你做的决定》，方便用户推翻。
- 有几类事即使授权了也要停下来问：
  - 推翻用户已确认的东西。
  - 一次花大量额度。
  - 审美二选一。
  - 前提缺失。
- 原因：这几类事要么不可逆，要么只有用户自己能判断。

## 五、已知难点（尚无稳定解法）

- 镜头转向正面时，道具不跟着转：只能单独描述道具朝向，多试几次。
- 局部编辑仍会波及别处：靠对比加局部贴回兜底。
- 大跨度的画风调整，用编辑模式改不动：只能用重生成，用脸的轻微变化换取质感。
- 计数类小细节：只能靠放大核对，逐张检查。
